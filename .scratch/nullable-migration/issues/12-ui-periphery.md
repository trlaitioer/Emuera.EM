Status: in-progress

Blocked by: 06, 07, 10

## 任务

- `Runtime/Config/`:Config.cs、ConfigData.cs、ConfigItem.cs、ConfigCode.cs、JSON/JSONConfig.cs、JSON/JSONConfigData.cs
- `Runtime/Utils/` 剩余:EvilMask/(Lang、Shape、Utils、ConsoleDivPart、ConsoleEscapedParts)、LangManager.cs、Preload.cs、SFMT.cs、Sys.cs、Sound.NAudio.cs、Sound.WMP.cs、NAudio_LoopStream.cs、WebPWrapper.cs、CharStream.cs、CtrlZ.cs、EmueraException.cs、EncodingHandler.cs、RegexFactory.cs、WinInput.cs、WinmmTimer.cs;另含由 issues/07、10 已启用的 EraStreamReader.cs、EraBinaryDataReader.cs、EraBinaryDataWriter.cs、EraDataStream.cs(本票只做回归核对,不重复启用)

### ConfigData 非空访问器

`ConfigDialog.cs` 141 条(位置口径)中 137 条出自查找 API 变可空:保存块的 111 处 `config.GetConfigItem(code).SetValue(...)` 只解引用,另在 `SetupLang`、`setCheckBox`/`setNumericUpDown`/`setColorBox` 与 `SetConfig` 的 13 处 `(ConfigItem<T>)` 转换各带出 CS8600 与 CS8602(第 14 处 `(ConfigItem<string>)` 在注释块内,不产生警告)。余下 4 条与查找 API 无关(`ConfigDialog.parent` 字段的 CS8618、`SetupLang` 内 `ComboBox.Items.Add` 取 `object?` 的 CS8604、`SaveConfig` 内 `(string)comboBox2.SelectedItem` 与 `comboBox7.SelectedItem as string` 各 1 条 CS8600)。逐处 `!` 会让 UI 内新增约 124 个断言,故本票新增访问器(issues/06 只改了查找 API 的返回标注,这 5 个访问器目前并不存在):

| 访问器 | 实现 | 调用方 |
| --- | --- | --- |
| `AConfigItem GetRequiredItem(ConfigCode)` | `GetItem(code)!` | `ConfigData.GetConfigValue<T>`、`ConfigData.LoadConfig` 的 `LastKey` 分支 |
| `AConfigItem GetRequiredConfigItem(ConfigCode)` | `GetConfigItem(code)!` | `ConfigDialog.cs` 保存块、`MainWindow.cs`、`Config.SetLanguageSetting`、`ConfigData.loadConfig` 里 `CompatiDRAWLINE` 改查 `CompatiLinefeedAs1739` 的重赋值 |
| `ConfigItem<T> GetRequiredConfigItem<T>(ConfigCode)` | `(ConfigItem<T>)GetConfigItem(code)!` | `ConfigDialog.cs` 的 `setCheckBox`/`setNumericUpDown`/`setColorBox` 与读取块 |
| `AConfigItem GetRequiredDebugItem(ConfigCode)` | `GetDebugItem(code)!` | `DebugConfigDialog.cs` 保存块 |
| `ConfigItem<T> GetRequiredDebugItem<T>(ConfigCode)` | `(ConfigItem<T>)GetDebugItem(code)!` | `DebugConfigDialog.cs` 的 `setCheckBox`/`setNumericUpDown` |

- 五个访问器均为 `internal`(`AConfigItem`/`ConfigItem<T>` 本身即 internal),不扩公共面
- 语义是「该处查找必中,未命中仍抛 NRE」,不引入新异常类型,不改运行行为;注释说明 `Required` 指结果被断言非空,而非新增抛出
- 按名查找的三个重载(`GetItem`/`GetConfigItem`/`GetReplaceItem`/`GetDebugItem` 的 `string` 版)保持 `AConfigItem?`:其入参来自配置文件与 ERB,未命中是有效状态,消费点(如 `loadConfig`、`GetConfigValueInERB`)的判空保留
