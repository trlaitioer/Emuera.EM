# C# 可空引用契约

[解释器项目](../../Emuera/Emuera.csproj)和[测试项目](../../Emuera.Tests/Emuera.Tests.csproj)开启可空引用分析，并将 nullable 警告作为构建错误。NAudio 与 WMP 各自编译的源码都遵循此要求。

声明应反映调用方实际可以获得的值。查找失败时可返回空值的配置 API 使用可空返回类型，翻译字符串在缺少翻译文本时使用默认文本。

`GlobalStatic` 按初始化完成后的访问契约声明非空成员，重置时集中清空。只有能够由具体类型和调用路径证明无需上下文时，解析期常量求值才可在非空 `ExpressionMediator` 参数上使用 `null!`。保留的断言在就近注释中说明所依赖的保证。

[断言计数脚本](../../scripts/count-bang-sites.ps1)用于复核源码中的后缀非空断言和变化趋势。逐项行为与回归以代码和测试为准。
